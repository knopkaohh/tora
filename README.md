# Академия Окинавского Каратэ

Сайт клуба «Тигр» / Тора: окинавское каратэ для детей, подростков и взрослых в Москве.

## Страницы

- Главная
- О академии
- Расписание
- Локации
- Тренеры
- Портфолио
- Стоимость
- Контакты

Пробное занятие бесплатное. Абонемент — 7 000 ₽ за 8 занятий в месяц. Телефон: `+7 495 003-777-3`.

- Третий: м. Смоленская, Новинский бульвар, д. 11, Центральная школа каратэ

## Запуск

Сайт собирается в корень домена `https://тигр-каратэ.рф`.

```bash
npm install
npm run dev
```

Локально открывайте [http://127.0.0.1:4179](http://127.0.0.1:4179).

Статическая сборка для хостинга:

```bash
npm run build
```

Готовые файлы лежат в `out/`. Распакуйте архив `tigr-karate-site.zip` в корень хоста (`public_html`), чтобы `index.html` и папка `media` оказались рядом, а не внутри второго каталога с именем архива.
