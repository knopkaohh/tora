# Академия Окинавского Каратэ

Сайт клуба «Тигр» / Тора: окинавское каратэ для детей, подростков и взрослых в Москве. Цвета и фотографии взяты с прежнего сайта на Тильде.

## Страницы

- Главная
- О академии
- Расписание
- Локации
- Тренеры
- Стоимость
- Контакты

Пробное занятие бесплатное. Абонемент — 7 000 ₽ за два занятия в неделю. Телефон: `+7 495 003-777-3`.

Залы:

- Основной: м. Савёловская — м. Дмитровская, ул. Складочная, д. 6с5, школа Марьина Роща имени Орлова
- Дополнительный: м. Савёловская, ул. Писцовая, д. 14, школа имени Пушкина
- Третий: м. Смоленская, Новинский бульвар, д. 11, Центральная школа каратэ

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:4179](http://127.0.0.1:4179), если сервер запущен так:

```bash
npm run dev -- --hostname 0.0.0.0 --port 4179
```

Сборка:

```bash
npm run build
npm start
```
