# Академия Окинавского Каратэ

Сайт клуба «Тигр» / Тора: окинавское каратэ для детей, подростков и взрослых в Москве. Цвета и фотографии взяты с прежнего сайта на Тильде.

## Страницы

- Главная
- О академии
- Расписание
- Локации
- Тренеры
- Стоимость
- Контакты

Пробное занятие бесплатное. Суммы абонементов на прежнем сайте не было, поэтому здесь они не выдуманы: стоимость называют по телефону `+7 495 003-77-73` до оплаты.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://127.0.0.1:4179](http://127.0.0.1:4179), если сервер запущен так:

```bash
npm run dev -- --hostname 0.0.0.0 --port 4179
```

Сборка:

```bash
npm run build
npm start
```
